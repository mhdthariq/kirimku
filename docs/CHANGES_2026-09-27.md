# Changes 2026-09-27 — Phase 1 of the clean-architecture plan

Continuing `docs/CLEAN_ARCHITECTURE_PLAN.md`. This pass covers **Phase 1**:
test scaffolding + unit tests for `src/lib/**`.

## Added
- **Vitest** as the test runner (`vitest.config.mts`, scripts `npm test`,
  `npm run test:watch`, `npm run test:coverage`).
- **38 unit tests**, all passing, across 3 files:
  - `src/lib/pricing.test.ts` (17 tests) — the volumetric formula, all three
    B2B pricing methods (kg/koli/cubic), rounding modes (UP/NEAREST),
    minimum-chargeable floors, multi-package summing, and the legacy-row
    (no `pricingMethod` set) fallback to `/kg`.
  - `src/lib/coordinates.test.ts` (15 tests) — decimal and DMS coordinate
    parsing, hemisphere sign handling, invalid input, round-tripping through
    `formatCoordinates`.
  - `src/lib/customer-display.test.ts` (6 tests) — B2C, B2B with a company
    name (the fixed case: company shows first, PIC second), B2B without a
    company name set (fallback), and a missing/unknown `type` field.

## Refactored (required to make the above testable)
- **Split `src/lib/pricing.ts` into two files.** The original file imported
  `@/lib/db` at module scope (for `resolveTariff` / `pricingPreview`), which
  made importing *any* part of the file — including the pure
  `computePricing` formula — fail outside of a live database connection.
  - `src/lib/pricing.ts` — now pure, framework/DB-free: `computePricing`,
    `normalizePricingMethod`, `volumetricKgForDetail`, and their types.
  - `src/lib/pricing-server.ts` (new) — `resolveTariff` and `pricingPreview`,
    which need `db`. Imports the pure functions from `./pricing`.
  - Updated the two consumers (`src/app/api/v1/shipments/[id]/route.ts`,
    `src/app/api/v1/shipments/[id]/price/route.ts`) to import from the right
    file. `src/lib/seed.ts` was unaffected (only used the pure function).
  - **No behavior change** — this is a pure code-organization split, and the
    38 tests above pass against the resulting pure module, which is exactly
    what confirms nothing broke.
